# OpenCode 数据库表与结构

本文档梳理 opencode 使用的 SQLite 数据库（单文件 `opencode.db`）中所有表及其结构、用途。Schema 由 Drizzle ORM 定义，入口汇总在 `packages/opencode/src/storage/schema.ts`。

---

## 1. 概览

| 模块 | 表名 | 用途 |
|------|------|------|
| project | **project** | 项目元信息（工作区路径、VCS、名称、沙箱等） |
| session | **session** | 会话（对话线程，含父子、目录、标题、权限等） |
| session | **message** | 消息元信息（归属会话、角色、模型、tokens 等；内容在 part） |
| session | **part** | 消息内容块（文本、工具调用、推理、附件等，一条消息多条 part） |
| session | **todo** | 会话待办列表（与 todowrite/todoread 工具对应） |
| session | **permission** | 项目级权限规则持久化（PermissionNext.Ruleset） |
| share | **session_share** | 会话分享（分享链接、secret 等） |
| control-plane | **workspace** | 控制平面工作区（类型、分支、目录、关联项目） |
| control | **control_account** | 控制账号（email、url、access/refresh token 等） |

所有表均使用 SQLite，主键与关联通过 Drizzle 的 `references` / `onDelete: "cascade"` 维护。部分表共用 **Timestamps**：`time_created`、`time_updated`（定义在 `storage/schema.sql.ts`）。

## 2. 项目与工作区

### 2.1 project（项目）

**文件**：`project/project.sql.ts`

| 列名 | 类型 | 说明 |
|------|------|------|
| id | text PK | 项目唯一 id |
| worktree | text NOT NULL | 工作区根目录绝对路径 |
| vcs | text | 版本控制系统（如 git） |
| name | text | 项目名称 |
| icon_url | text | 图标 URL |
| icon_color | text | 图标颜色 |
| time_created | integer NOT NULL | 创建时间戳 |
| time_updated | integer NOT NULL | 更新时间戳 |
| time_initialized | integer | 初始化完成时间 |
| sandboxes | text (JSON) NOT NULL | 沙箱路径列表 `string[]` |
| commands | text (JSON) | 命令配置 `{ start?: string }` |

**用途**：表示一个 opencode 项目（通常对应一个代码仓库/工作区）。会话、权限、工作区等通过 `project_id` 关联到项目。

---

### 2.2 workspace（控制平面工作区）

**文件**：`control-plane/workspace.sql.ts`

| 列名 | 类型 | 说明 |
|------|------|------|
| id | text PK | 工作区 id |
| type | text NOT NULL | 工作区类型 |
| branch | text | 分支名 |
| name | text | 名称 |
| directory | text | 目录 |
| extra | text (JSON) | 扩展信息 |
| project_id | text NOT NULL FK → project.id CASCADE | 所属项目 |

**用途**：控制平面（如云端/协同）中的工作区实体，与本地 project 关联，用于多工作区、分支等场景。

---

## 3. 会话与消息

### 3.1 session（会话）

**文件**：`session/session.sql.ts`

| 列名 | 类型 | 说明 |
|------|------|------|
| id | text PK | 会话唯一 id |
| project_id | text NOT NULL FK → project.id CASCADE | 所属项目 |
| workspace_id | text | 关联控制平面工作区（可选） |
| parent_id | text | 父会话 id（子任务/子 agent 会话指向主会话） |
| slug | text NOT NULL | 短标识 |
| directory | text NOT NULL | 会话对应目录（通常即项目目录） |
| title | text NOT NULL | 会话标题 |
| version | text NOT NULL | 版本标识 |
| share_url | text | 分享链接 |
| summary_additions | integer | 摘要统计：新增行数 |
| summary_deletions | integer | 摘要统计：删除行数 |
| summary_files | integer | 摘要统计：涉及文件数 |
| summary_diffs | text (JSON) | 摘要中的文件 diff 列表 `Snapshot.FileDiff[]` |
| revert | text (JSON) | 回滚信息 `{ messageID, partID?, snapshot?, diff? }` |
| permission | text (JSON) | 会话级权限规则 `PermissionNext.Ruleset` |
| time_created | integer NOT NULL | 创建时间 |
| time_updated | integer NOT NULL | 更新时间 |
| time_compacting | integer | 压缩中状态时间戳 |
| time_archived | integer | 归档时间 |

**用途**：一条对话线程。可带父会话（子任务）、目录、标题、摘要与回滚信息；权限可覆盖项目默认。

---

### 3.2 message（消息）

**文件**：`session/session.sql.ts`

| 列名 | 类型 | 说明 |
|------|------|------|
| id | text PK | 消息唯一 id |
| session_id | text NOT NULL FK → session.id CASCADE | 所属会话 |
| time_created | integer NOT NULL | 创建时间 |
| time_updated | integer NOT NULL | 更新时间 |
| data | text (JSON) NOT NULL | 消息元信息（不含 id、sessionID） |

**data 内容（InfoData）**：角色（user/assistant）、parentID、agent、model、tokens、time、error、finish、summary、path、cost、variant 等，见 `MessageV2.Info` / `MessageV2.User` / `MessageV2.Assistant`。实际正文与工具调用等内容在 **part** 表中。

**用途**：表示一条“消息”的元数据；内容由多条 part 组成，便于流式追加与按块更新。

---

### 3.3 part（消息块）

**文件**：`session/session.sql.ts`

| 列名 | 类型 | 说明 |
|------|------|------|
| id | text PK | part 唯一 id |
| message_id | text NOT NULL FK → message.id CASCADE | 所属消息 |
| session_id | text NOT NULL | 冗余会话 id（便于按会话查 part） |
| time_created | integer NOT NULL | 创建时间 |
| time_updated | integer NOT NULL | 更新时间 |
| data | text (JSON) NOT NULL | 块内容（类型与载荷） |

**data 内容（PartData）**：由 `type` 区分的多种 part：text、file、tool（含 state：pending/running/completed/error）、reasoning、step-start、step-finish、subtask、compaction、agent、retry、patch 等，见 `MessageV2.Part`。

**用途**：存储单条消息内的文本、附件、工具调用、推理、步骤等；支持流式写入与 updatePart/updatePartDelta 的局部更新。

---

### 3.4 todo（会话待办）

**文件**：`session/session.sql.ts`

| 列名 | 类型 | 说明 |
|------|------|------|
| session_id | text NOT NULL FK → session.id CASCADE | 所属会话 |
| content | text NOT NULL | 待办内容 |
| status | text NOT NULL | 状态 |
| priority | text NOT NULL | 优先级 |
| position | integer NOT NULL | 排序位置 |
| time_created | integer NOT NULL | 创建时间 |
| time_updated | integer NOT NULL | 更新时间 |

**主键**：`(session_id, position)`。

**用途**：与 todowrite/todoread 工具对应，存储该会话的待办列表；子 agent 会话可配置为不可写待办。

---

### 3.5 permission（项目权限持久化）

**文件**：`session/session.sql.ts`

| 列名 | 类型 | 说明 |
|------|------|------|
| project_id | text PK FK → project.id CASCADE | 项目 id |
| time_created | integer NOT NULL | 创建时间 |
| time_updated | integer NOT NULL | 更新时间 |
| data | text (JSON) NOT NULL | 权限规则 `PermissionNext.Ruleset` |

**用途**：持久化用户在权限弹窗中选择的“始终允许”等规则（如 doom_loop、read、edit 等），避免每次重复询问。

---

## 4. 分享

### 4.1 session_share（会话分享）

**文件**：`share/share.sql.ts`

| 列名 | 类型 | 说明 |
|------|------|------|
| session_id | text PK FK → session.id CASCADE | 被分享的会话 |
| id | text NOT NULL | 分享 id |
| secret | text NOT NULL | 访问密钥 |
| url | text NOT NULL | 分享 URL |
| time_created | integer NOT NULL | 创建时间 |
| time_updated | integer NOT NULL | 更新时间 |

**用途**：会话分享链接与密钥，用于只读或协同查看会话。

---

## 5. 控制账号

### 5.1 control_account（控制账号）

**文件**：`control/control.sql.ts`

| 列名 | 类型 | 说明 |
|------|------|------|
| email | text NOT NULL | 账号邮箱 |
| url | text NOT NULL | 控制服务 URL |
| access_token | text NOT NULL | 访问令牌 |
| refresh_token | text NOT NULL | 刷新令牌 |
| token_expiry | integer | 令牌过期时间 |
| active | integer (boolean) NOT NULL DEFAULT false | 是否当前激活 |
| time_created | integer NOT NULL | 创建时间 |
| time_updated | integer NOT NULL | 更新时间 |

**主键**：`(email, url)`。

**用途**：存储与控制平面（如 opencode 云端）的账号与 token，用于鉴权与同步。

---

## 6. 表关系简图

```
project
  ├── session (project_id) [CASCADE]
  │     ├── message (session_id) [CASCADE]
  │     │     └── part (message_id) [CASCADE]
  │     ├── todo (session_id) [CASCADE]
  │     ├── session_share (session_id) [CASCADE]
  │     └── session.parent_id → session.id（自关联，子会话）
  ├── permission (project_id) [CASCADE]
  └── workspace (project_id) [CASCADE]

control_account：独立表，(email, url) 主键
```

---

## 7. 相关代码位置

- **Schema 汇总**：`storage/schema.ts`（导出上述所有表）
- **数据库初始化与迁移**：`storage/db.ts`（Bun SQLite + Drizzle，`opencode.db`）
- **会话/消息/part 读写**：`session/index.ts`、`session/message-v2.ts`
- **项目**：`project/project.ts`
- **权限**：`permission/next.ts`（会读写 permission 表与 Session 的 permission 字段）
- **JSON 迁移**：`storage/json-migration.ts`（从旧 JSON 存储迁移到上述表）
