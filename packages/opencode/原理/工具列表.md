# OpenCode 工具列表

本文档梳理 opencode 内置的 Agent 工具及其作用。工具注册在 `packages/opencode/src/tool/registry.ts`，部分工具根据配置或环境变量有条件启用。

---

## 一、文件与代码

### read

- **作用**：从本地文件系统读取文件或目录内容。
- **典型用法**：读源码、看目录结构、按行号分段读大文件（支持 offset/limit）。
- **说明**：支持图片与 PDF（以附件返回）；单行超长会截断；目录返回条目列表（子目录带 `/`）；需 read 权限。

### write

- **作用**：将一段内容整文件写入指定路径。
- **典型用法**：新建文件或覆盖已有文件。
- **说明**：写入前用 edit 权限做 diff 确认；写完后会拉取 LSP 诊断并在 output 中返回错误提示。

### edit

- **作用**：在已有文件中做“查找并替换”（oldString → newString）。
- **典型用法**：局部修改、多行替换；支持 replaceAll。
- **说明**：内部有多重匹配策略（精确、忽略空白、块锚点等）；需 edit 权限；会返回 LSP 诊断。

### apply_patch

- **作用**：用统一 patch 格式一次性完成增/删/改/移动文件。
- **典型用法**：多文件、大块修改；格式为 `*** Begin Patch` / `*** Add File` / `*** Update File` / `*** Delete File` 等。
- **说明**：仅在部分模型下启用（如非 gpt-4 的 gpt-*）；启用时通常会关闭 edit/write，与 edit/write 二选一。

### grep

- **作用**：按正则搜索文件内容，返回匹配到的文件路径、行号与行内容。
- **典型用法**：找函数名、类名、字符串、模式；可用 include 限定文件类型（如 `*.ts`）。
- **说明**：基于 ripgrep；结果按修改时间排序；需 grep 权限。

### glob

- **作用**：按 glob 模式匹配文件名，返回匹配到的文件路径列表。
- **典型用法**：找 `**/*.ts`、`src/**/*.tsx` 等；可与 grep 配合做多轮检索。
- **说明**：结果按修改时间排序；需 glob 权限。

## 二、终端与执行

### bash

- **作用**：在持久化 shell 中执行一条命令，支持超时与工作目录。
- **典型用法**：git、npm、docker、构建、测试等终端操作。
- **说明**：不用于读/写/搜文件，应用 read/write/edit/grep/glob；需提供简短 description；可指定 workdir、timeout。

---

## 三、子代理与任务

### task

- **作用**：启动子 agent（subagent）处理复杂或多步任务，由主 agent 传入 prompt 与 subagent_type。
- **典型用法**：探索代码库（explore）、通用多步任务（general）、自定义 slash 命令、并行执行多个子任务。
- **说明**：每次调用可新建子会话或通过 task_id 恢复同一子会话；子会话有独立权限（如禁用 todoread/todowrite）；返回结果中含 task_id 供续用。

---

## 四、网络与检索

### webfetch

- **作用**：请求指定 URL，拉取网页或资源内容。
- **典型用法**：查文档、抓取公开页面内容。
- **说明**：支持 format：text / markdown / html；有大小与超时限制；需 webfetch 权限。

### websearch

- **作用**：执行网络搜索，返回与查询相关的检索结果/摘要。
- **典型用法**：查最新信息、文档、示例。
- **说明**：依赖 Exa MCP（zen 用户或 OPENCODE_ENABLE_EXA）；参数含 query、numResults、livecrawl、type 等。

### codesearch

- **作用**：面向 API/库/SDK 的代码与文档上下文检索，返回与查询相关的代码/文档片段。
- **典型用法**：查“React useState 用法”“pandas 过滤”等。
- **说明**：同样依赖 Exa；可指定 tokensNum 控制返回长度；与 websearch 一样在 zen 或 OPENCODE_ENABLE_EXA 下启用。

---

## 五、会话与协作

### todowrite

- **作用**：更新当前会话的待办列表（写入一组 todo 项）。
- **典型用法**：主 agent 维护任务列表、进度、状态。
- **说明**：需 todowrite 权限；子 agent 会话可被配置为禁止使用。

### todoread

- **作用**：读取当前会话的待办列表。
- **说明**：在 registry 中当前被注释掉，未默认暴露给 agent。

### question

- **作用**：向用户发起一组问题，收集选项或自定义回答。
- **典型用法**：确认需求、选方案、澄清歧义。
- **说明**：仅在 app/cli/desktop 客户端或开启 OPENCODE_ENABLE_QUESTION_TOOL 时注册。

---

## 六、技能与扩展

### skill

- **作用**：加载预置的“技能”（Skill），将领域说明、工作流和资源注入当前上下文。
- **典型用法**：任务匹配到某技能描述时，调用 skill 加载对应 SKILL.md 与资源。
- **说明**：技能列表来自配置与 .cursor/skills 等；输出含 `<skill_content>` 与技能内文件列表；需 skill 权限。

---

## 七、批量与实验性

### batch

- **作用**：在一次调用中并行执行多笔工具调用（tool_calls 数组）。
- **典型用法**：一次发起多组 read/grep/glob 等，减少往返。
- **说明**：需配置 `experimental.batch_tool: true`；单次最多 25 个调用；不允许再嵌套 batch。

### lsp

- **作用**：对指定文件/位置执行 LSP 操作（跳定义、查引用、hover、符号等）。
- **典型用法**：goToDefinition、findReferences、hover、documentSymbol、workspaceSymbol 等。
- **说明**：需开启 OPENCODE_EXPERIMENTAL_LSP_TOOL；依赖当前工作区已启用的 LSP 服务。

### plan_exit

- **作用**：在“计划模式”下，确认计划完成后询问是否切换到 build agent 开始执行。
- **典型用法**：与 Plan 子 agent / 计划流程配合，从规划切到实施。
- **说明**：仅在 OPENCODE_EXPERIMENTAL_PLAN_MODE 且 CLI 客户端时注册。

---

## 八、占位与自定义

### invalid

- **作用**：占位工具，用于模型传入了无效或未知工具名时返回友好错误信息。
- **说明**：不供 agent 主动选用，仅做兜底。

### 自定义工具

- **来源**：配置目录下的 `tool/` 或 `tools/` 中的 `*.js`/`*.ts`，以及插件的 `tool` 定义。
- **说明**：通过 `ToolRegistry.register()` 与插件体系挂载，与内置工具一起参与 `ToolRegistry.tools()`，按 agent 与权限过滤后提供给模型。
